# 🛒 Sistema de Desconto Progressivo

[![Python](https://img.shields.io/badge/Python-3.x-blue?style=flat-square&logo=python&logoColor=white)](https://www.python.org/)
[![GitHub](https://img.shields.io/badge/GitHub-DaniAKil-lightgrey?style=flat-square&logo=github)](https://github.com/DaniAKil)

Aplicação em Python desenvolvida para implementar um sistema automatizado de desconto progressivo para uma loja online, calculando os valores de forma dinâmica com base no total da compra.

---

## 📋 Regras de Negócio

O sistema aplica os percentuais de desconto de acordo com a faixa de preço:
* **Menor que R$ 200,00:** Desconto de **5%**
* **De R$ 200,00 até R$ 299,99:** Desconto de **10%**
* **Maior ou igual a R$ 300,00:** Desconto de **15%**
